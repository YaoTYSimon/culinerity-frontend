# Craving restaurants: where to get it (Melbourne, independent venues)

Checked 2026-11-23. Method: operator pages only (venue's own site, or the venue's own ordering/menu page), one read each, no aggregator, map, review or delivery-marketplace content. No prices recorded. Dish names are recorded as facts, no menu text copied. Address is as printed on the operator page.

Caveats for the reader:
- Page date: almost no venue page carries a publication date. Every page below shows only a footer copyright year (2026 unless stated), so the date seen is "undated (footer (c) 2026)". The Rule "current dated official listing" is therefore met only weakly; treat these as "operator page, undated".
- Rows marked [ordering] are the venue's own white-label ordering page (Yumbo Jumbo or TuckerFox storefront operated for that venue), not a delivery marketplace. Review if you want to exclude that platform.
- Craving names are given only where the page printed a dish name. "Fish and chips" is listed only where the page named a fish dish.
